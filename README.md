# טאבו זוגי בעברית

משחק לשני שחקנים על טלפון אחד, עם 64 קלפים וחמש מילים אסורות בכל קלף.

## העלאה ל־GitHub ו־Vercel

חלצו את ZIP והעלו את הקבצים והתיקייה `public` לשורש המאגר. `package.json` צריך להיות בשורש.
אין צורך להעלות את `dist`, ואין להעלות `node_modules`.
ב־Vercel בחרו Vite, פקודת בנייה `npm run build` ותיקיית פלט `dist`.

## התקנה באייפון

לאחר הפרסום, פתחו את הקישור ב־Safari, לחצו שיתוף ואז הוספה למסך הבית.
אפשרו פתיחה כאפליקציית אינטרנט אם האפשרות מופיעה.
פתחו פעם ראשונה עם חיבור לאינטרנט והמתינו לטעינה; לאחר מכן הקבצים נשמרים לעבודה ללא אינטרנט.

## שמירה

שמות השחקנים, ההגדרות והקלפים האישיים נשמרים במכשיר. משחק פעיל והניקוד אינם משוחזרים לאחר סגירה או רענון.
קלפים אישיים מופיעים ברמת מעורב. לאחר שימוש בכל הקלפים, החפיסה מתערבבת מחדש.

## בדיקות

הבנייה עברה. 17 בדיקות אוטומטיות בדקו סינון קושי, 64 קלפים ללא חזרות לפני סיום החפיסה,
חמש מילים בכל קלף, ניקוד עם ובלי קנס, השהיה, החלפת תפקידים, משחק חדש,
שמירה, נתוני שמירה פגומים או חסומים, ותום זמן לאחר מעבר לרקע.
בדיקות נוספות בדקו את מטמון העבודה ללא אינטרנט, ניקוי גרסאות ישנות ואייקונים.
הבדיקות נעשו בסביבת DOM מדומה. התקנה ומראה ב־Safari באייפון עדיין דורשים בדיקה אחרי הפרסום.

מאגר GitHub פרטי שומר את קוד המקור פרטי; הגבלת הגישה למשחק עצמו דורשת הגדרה נפרדת.
